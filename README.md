# حملتي · Hamlaty — hamlaty.co

منصة تربط حملات الزيارة بفنادق كربلاء والنجف والكاظمية وسامراء وبمكاتب حجوزات الطيران. الحملة ترسل طلب مجموعة واحداً (عدد الزوار، المدن، الليالي، الغرف والوجبات، ورحلات الطيران)، والفنادق والمكاتب الموثّقة ترسل عروضها، والحملة تقارن وتحجز، ومقدّم الخدمة يؤكد. الواجهة بالعربية والإنجليزية.

## الرسوم

- المنصة مجانية للحملات، والتسجيل وإرسال العروض مجاني للفنادق والمكاتب. لا أحد يدفع مقدماً.
- **1$ عن كل زائر لكل فندق يُحجز**، و**3$ عن كل تذكرة طيران** (تذكرة الذهاب والعودة واحدة). المبلغان في `app_settings` ويُغيَّران دون برمجة.
- الرسوم جزء من العربون: بعد أن يؤكد مقدّم الخدمة، تدفعها الحملة لحملتي والباقي لمقدّم الخدمة. يسجّل فريق حملتي الدفع من `/admin` (لاحقاً بوابة الدفع)، فيتأكد الحجز وتظهر بيانات الطرفين.

مشروع مستقل تماماً عن Qotoo: مستودع وقاعدة بيانات واستضافة منفصلة.

## قاعدة البيانات

يُشغَّل بالترتيب في SQL Editor:

1. `supabase/migrations/0001_init.sql`: الحسابات، ملفات الفنادق، الطلبات والإقامات، العروض وأسطرها، الحجوزات، الرسائل، الرحلات والزوار.
2. `supabase/migrations/0002_fees_and_flights.sql`: الرسوم الثابتة بدل العمولة، ومكاتب الطيران (الملفات، رحلات الطلب، عروض الطيران وأسطرها، حجوزات الطيران).

بعد الملفين: 19 جدولاً، 37 دالة، 3 إعدادات.

قواعد تفرضها قاعدة البيانات نفسها:

- لا يرى أي طرف اسم الطرف الآخر أو رقمه قبل أن يؤكد مقدّم الخدمة وتُدفع رسوم حملتي (`booking_contacts`).
- أرقام الهواتف والبريد والروابط تُخفى تلقائياً في الرسائل والملاحظات قبل الحجز (`mask_contacts`).
- الفندق أو المكتب يرى الطلب فقط إذا وُجّه إليه، ولا يرى عروض غيره. الحملة لا ترى مسودات العروض. المكتب يتلقى طلبات الدول التي يخدمها فقط.
- إجمالي العرض تحسبه قاعدة البيانات من أسعار الغرف، ولا يتغير السعر بعد الإرسال.
- الفندق يسعّر الإقامة في مدينته فقط، وتغيير مدينته أو نجومه أو مسافته يعيده للمراجعة.
- الرسوم تحسبها قاعدة البيانات: عدد الزوار × 1$ لكل فندق، وعدد التذاكر × 3$. تسجيل الدفع لفريق حملتي فقط (`mark_fee_paid`).
- بيانات الزوار تراها الحملة المنظمة فقط. الزائر يسجل نفسه برابط الرحلة دون حساب.
- صلاحيات الإدارة تحتاج رمز تطبيق المصادقة إضافة لرمز الجوال.

## الإعداد

### 1. Supabase (مشروع جديد باسم hamlaty، وليس مشروع Qotoo)
1. SQL Editor ← الصق محتوى `supabase/migrations/0001_init.sql` ← Run.
2. Authentication ← Sign In / Providers ← Phone ← فعّله واختر Twilio.
3. بعد أول دخول لك، اجعل حسابك مديراً:
   ```sql
   update profiles set is_admin = true where phone = '968XXXXXXXX';
   ```
   ثم افتح `/admin` وفعّل تطبيق المصادقة.

### 2. Vercel
استورد المستودع، وأضف متغيرات البيئة من `.env.example`، ثم اربط النطاق hamlaty.co (الرئيسي) وhamlaty.app.

### 3. النسخ الاحتياطي
انظر `docs/BACKUP.md`. لا يعمل إلا بعد إضافة `SUPABASE_DB_URL` و`BACKUP_PASSPHRASE` في إعدادات GitHub.
