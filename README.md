# حملتي · Hamlaty — hamlaty.co

منصة تربط حملات الزيارة بفنادق كربلاء والنجف والكاظمية وسامراء. الحملة ترسل طلب مجموعة واحداً (عدد الزوار، المدن، الليالي، الغرف والوجبات)، والفنادق الموثّقة ترسل عروضها، والحملة تقارن وتحجز، والفندق يؤكد. الواجهة بالعربية والإنجليزية.

مشروع مستقل تماماً عن Qotoo: مستودع وقاعدة بيانات واستضافة منفصلة.

## قاعدة البيانات

`supabase/migrations/0001_init.sql` يبني كل شيء: الحسابات، ملفات الفنادق، الطلبات والإقامات، العروض وأسطرها، الحجوزات والعمولة، رصيد الحملات، الرسائل، الرحلات والزوار.

قواعد تفرضها قاعدة البيانات نفسها:

- لا يرى أي طرف اسم الطرف الآخر أو رقمه قبل أن يؤكد الفندق الحجز (`booking_contacts`).
- أرقام الهواتف والبريد والروابط تُخفى تلقائياً في الرسائل والملاحظات قبل الحجز (`mask_contacts`).
- الفندق يرى الطلب فقط إذا وُجّه إليه، ولا يرى عروض الفنادق الأخرى. الحملة لا ترى مسودات العروض.
- إجمالي العرض تحسبه قاعدة البيانات من أسعار الغرف، ولا يتغير السعر بعد الإرسال.
- الفندق يسعّر الإقامة في مدينته فقط، وتغيير مدينته أو نجومه أو مسافته يعيده للمراجعة.
- العمولة تقل مع تكرار الحجز بين الحملة والفندق نفسيهما: 5% ثم 2% ثم 1% (`app_settings`).
- الحملة تكسب 1% رصيداً عند اكتمال الحجز.
- بيانات الزوار تراها الحملة المنظمة فقط. الزائر يسجل نفسه برابط الرحلة دون حساب.
- صلاحيات الإدارة تحتاج رمز تطبيق المصادقة إضافة لرمز الجوال.

## الإعداد

### 1. Supabase (مشروع جديد باسم hamlaty، وليس مشروع Qotoo)
1. SQL Editor ← الصق محتوى `supabase/migrations/0001_init.sql` ← Run.
2. Authentication ← Sign In / Providers ← Phone ← فعّله واختر Twilio.
3. بعد أول دخول لك، اجعل حسابك مديراً:
   ```sql
   update profiles set is_admin = true where phone = '968XXXXXXXX';
   ```
   ثم افتح `/admin` وفعّل تطبيق المصادقة.

### 2. Vercel
استورد المستودع، وأضف متغيرات البيئة من `.env.example`، ثم اربط النطاق hamlaty.co (الرئيسي) وhamlaty.app.

### 3. النسخ الاحتياطي
انظر `docs/BACKUP.md`. لا يعمل إلا بعد إضافة `SUPABASE_DB_URL` و`BACKUP_PASSPHRASE` في إعدادات GitHub.
